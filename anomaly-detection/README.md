# Anomaly Detection — Isolation Forest

Поиск аномальных наблюдений без учителя и исследование чувствительности модели к гиперпараметрам на контролируемом синтетическом наборе данных.

## [Обнаружение аномалий методом Isolation Forest](./%D0%9F%D0%A013_%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B_%D0%98%D0%98.ipynb)

- Сгенерировала 100 обычных наблюдений и 20 выбросов; истинные метки не использовались для обучения.
- Обучила Isolation Forest, визуализировала предсказания и значения `decision_function` относительно нулевого порога.
- Сравнила девять комбинаций параметров: `contamination` = 0,05 / 0,15 / 0,20 и `n_estimators` = 50 / 100 / 200.

| contamination | Найдено истинных выбросов | Ложные срабатывания |
|---|---:|---:|
| 0,05 | 6 | 0 |
| 0,15 | 18 | 0 |
| 0,20 | 18 | 6 |

**Результат:** при contamination = 0,15 обнаружено 18 из 20 выбросов без ложных срабатываний (Precision = 100%, Recall = 90%, рассчитаны по сохранённым результатам). Изменение числа деревьев не повлияло на эти показатели в данном эксперименте.

Оценка выполнена на тех же синтетических наблюдениях, на которых обучалась модель; независимая тестовая выборка не использовалась.

## Технологии

Python, NumPy, pandas, scikit-learn, Matplotlib.
