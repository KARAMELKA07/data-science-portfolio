# Clustering — обучение без учителя

Исследование алгоритмов кластеризации на синтетических и табличных данных с оценкой качества разбиения и анализом влияния геометрии кластеров.

## [KMeans и выбор числа кластеров](./%D0%9F%D0%A05%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B%20%D0%98%D0%98.ipynb)

- Применила KMeans к синтетическим данным и датасету Iris.
- Сравнила метод локтя и Silhouette Score для выбора k; сопоставила кластеры Iris с истинными классами по Adjusted Rand Index (ARI).
- Выполнила сегментацию пассажиров Titanic по возрасту и стоимости билета со стандартизацией признаков и анализом профилей кластеров.

**Результат:** для Iris максимальный Silhouette Score получен при k = 2, метод локтя указал на k = 3. Для разбиения на три кластера ARI составил около 0,60.

## [KMeans, агломеративная кластеризация и DBSCAN](./%D0%9F%D0%A06%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B%20%D0%98%D0%98.ipynb)

- Сравнила методы на нелинейных структурах `make_moons` и `make_circles`.
- Построила дендрограммы и визуализировала результаты кластеризации.
- Применила DBSCAN к стандартизированным признакам Iris, исследовала выделение шумовых точек.

**Результат:** на Iris DBSCAN выделил два кластера и четыре шумовые точки; 49 из 50 объектов setosa вошли в один кластер, но versicolor и virginica не были разделены на отдельные группы. Эксперимент демонстрирует ограничения метода на конкретных данных.

## Технологии
