## Проекты

### Classification
Классификация данных, обучение и сравнение моделей.

- Логистическая регрессия, оценка качества и кросс-валидация.
- Деревья решений, настройка гиперпараметров с GridSearchCV.
- Random Forest и Gradient Boosting, анализ важности признаков.

### Regression
Построение регрессионных моделей для прогнозирования числовых значений.

- Множественная линейная регрессия.
- Генерация признаков.
- Ridge, Lasso, подбор гиперпараметров.

### Clustering
Кластеризация данных без заранее известных меток классов.

- KMeans.
- DBSCAN.
- Иерархическая кластеризация.
- Визуализация и сравнение алгоритмов.

### Time Series Forecasting
Анализ временных рядов и построение прогнозов.

- Анализ тренда и сезонности.
- Скользящая средняя и экспоненциальное сглаживание.
- Модели Хольта—Уинтерса и Тейла—Вейджа.
- ARIMA, SARIMA.
- Оценка ошибок прогнозирования и анализ остатков.

### Anomaly Detection
Поиск аномальных наблюдений в данных.

- Isolation Forest.
- Визуализация найденных выбросов.
- Анализ функции решения и настройка параметров модели.

### Neural Networks
Применение простых нейронных сетей для классификации.

- Многослойный перцептрон (MLP).
- Функция активации ReLU и оптимизатор Adam.
- Сравнение нейронной сети с логистической регрессией.
- Визуализация границ классификации.

### Decision Support
Методы поддержки принятия решений.

- Метод анализа иерархий (AHP).
- Многокритериальный анализ.
- Когнитивные карты.
- Имитационное моделирование бизнес-сценариев.
