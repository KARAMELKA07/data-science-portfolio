# Data Science Portfolio

Привет! Меня зовут Карина Закирова. Я учусь в магистратуре РТУ МИРЭА по направлению «Искусственный интеллект и машинное обучение для решения прикладных задач».

В этом репозитории собраны мои учебные практические работы по Data Science и классическому машинному обучению на Python.

## Проекты

- **Classification** — бинарная классификация, логистическая регрессия, оценка качества моделей, кросс-валидация.
- **Housing Regression** — множественная линейная регрессия, генерация признаков, Ridge, Lasso, подбор гиперпараметров.
- **Time Series Forecasting** — анализ временных рядов, тренды, сезонность, ARIMA, SARIMA.
- **Clustering** — KMeans, DBSCAN, иерархическая кластеризация, сравнение алгоритмов.
- **Decision Support** — метод анализа иерархий (AHP), многокритериальное принятие решений, когнитивные карты и имитационное моделирование бизнес-сценариев.

## Технологии

Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, SciPy, statsmodels, pmdarima, Jupyter Notebook.
