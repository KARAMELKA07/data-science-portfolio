# Classification — бинарная классификация

Сравнение методов обучения с учителем на датасете Breast Cancer Wisconsin: оценка качества, отбор признаков, настройка гиперпараметров и интерпретация моделей.

## [Логистическая регрессия и отбор признаков](./%D0%9F%D0%A09%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B%20%D0%98%D0%98.ipynb)

- Разделила данные на обучающую и тестовую выборки, выполнила стандартизацию признаков и обучила Logistic Regression.
- Оценила модель по Accuracy, Precision, Recall, F1-score, ROC-AUC и матрице ошибок; провела кросс-валидацию.
- Отобрала 10 признаков по абсолютным значениям коэффициентов модели и сравнила качество с исходным набором из 30 признаков.

**Результат:** тестовая Accuracy — 98,2%, Precision, Recall и F1-score — 98,6% каждый. Количество признаков сокращено с 30 до 10 без снижения Accuracy в этом эксперименте.

## [Деревья решений и ансамбли](./%D0%9F%D0%A012_%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B_%D0%98%D0%98%20%281%29.ipynb)

- Обучила Decision Tree, проанализировала переобучение и визуализировала структуру дерева.
- Подобрала `max_depth` и `min_samples_leaf` с помощью GridSearchCV.
- Сравнила дерево, Random Forest и Gradient Boosting; исследовала важность признаков и время обучения.

| Модель | Test Accuracy |
|---|---:|
| Decision Tree | 91,23% |
| Decision Tree после настройки | 93,86% |
| Random Forest | 95,61% |
| Gradient Boosting | 95,61% |

Настройка дерева уменьшила разрыв между обучающей и тестовой точностью. Результаты относятся к конкретным разбиениям данных в блокнотах, а не к клинической валидации.

Python, pandas, NumPy, scikit-learn, Matplotlib.
