# Neural Networks — нелинейная классификация

Сравнение линейного классификатора и многослойного перцептрона на синтетическом датасете make_moons из 1 000 объектов двух классов.

## [Многослойный перцептрон (MLP)](./%D0%9F%D0%A014_%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B_%D0%98%D0%98.ipynb)

- Сгенерировала данные и разделила их на обучающую, валидационную и тестовую выборки.
- Выполнила стандартизацию и обучила Logistic Regression как базовую модель.
- Построила MLPClassifier с двумя скрытыми слоями по 16 нейронов, активацией ReLU и оптимизатором Adam.
- Сравнила Accuracy и визуализировала границы принятия решений, чтобы исследовать способность моделей описывать нелинейные зависимости.

| Модель | Test Accuracy |
|---|---:|
| Logistic Regression | 88,0% |
| MLPClassifier | 97,5% |

**Результат:** MLP повысил тестовую Accuracy на 9,5 процентного пункта относительно линейной базовой модели. Результат относится к конкретному синтетическому датасету; нейронная сеть реализована средствами scikit-learn.

## Технологии

Python, NumPy, pandas, scikit-learn, Matplotlib.
