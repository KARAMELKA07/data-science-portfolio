# Housing Regression — прогнозирование стоимости жилья

Построение регрессионных моделей на California Housing с исследованием влияния масштаба признаков, полиномиального расширения и регуляризации на качество прогноза.

## [Множественная линейная регрессия](./%D0%9F%D0%A03%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B%20%D0%98%D0%98.ipynb)

- Обучила Linear Regression на исходных признаках, исследовала коэффициенты модели.
- Сравнила качество до и после стандартизации с помощью MSE и R².

**Результат:** MSE = 0,5559, R² = 0,5758. Стандартизация изменила коэффициенты, но практически не повлияла на предсказания.

## [Feature Engineering и регуляризация](./%D0%9F%D0%A04%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B%20%D0%98%D0%98.ipynb)

- Сформировала полиномиальные признаки второй степени для учёта нелинейных зависимостей.
- Применила Ridge (L2), подобрала alpha с помощью GridSearchCV и сравнила коэффициенты.
- Исследовала Lasso (L1) и сопоставила четыре модели по R².

| Модель | R² |
|---|---:|
| Linear Regression | 0,5758 |
| Linear Regression + Polynomial Features | 0,6457 |
| Ridge | 0,6417 |
| Lasso | 0,6484 |

**Результат:** максимальный R² среди рассмотренных вариантов — 0,6484 у Lasso, против 0,5758 у базовой модели. Это сравнение на тестовых данных из учебного эксперимента.

## Технологии

Python, pandas, scikit-learn.
